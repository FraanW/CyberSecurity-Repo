Step 0 · The app's own login

Log in without any IdP

This is the app before federation: it checks your password itself. Use it to confirm the deployment is healthy, then compare it with the SAML login in Step 3 — same app, same session cookie, a completely different trust story.

Credentials come from LAB_LOCAL_USERNAME / LAB_LOCAL_PASSWORD. If you did not set a password, one was generated and printed in the service logs at startup.
