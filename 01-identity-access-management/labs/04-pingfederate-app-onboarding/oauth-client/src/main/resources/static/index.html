Step 0 · The app's own login

Log in without any authorization server

This is the app before OAuth: it checks your password itself and issues no tokens at all. Use it to confirm the deployment is healthy, then compare with Step 3 — same app, same session cookie, a completely different trust story.

Credentials come from LAB_LOCAL_USERNAME / LAB_LOCAL_PASSWORD. If you did not set a password, one was generated and printed in the service logs at startup.

    Step 3 · Authorization Code + PKCE

    You are not logged in

    “Log in” sends you to PingFederate's authorization endpoint. You authenticate there, PingFederate redirects back with a one-time code, and this backend swaps that code for tokens — over a back channel your browser never sees.
